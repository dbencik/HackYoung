# HackYoung — Ethical Hacking for Youngsters

24 hands-on ethical hacking and cybersecurity lessons for teenagers. Learn to hack. Learn to defend. Stay legal.

## Modules

1. **The Hacker Mindset** — Ethics, legality, how hackers think, and your lab setup.
2. **Network Fundamentals** — IP addresses, ports, protocols, and packet sniffing.
3. **Scanning & Reconnaissance** — Nmap, OSINT, footprinting, and enumeration.
4. **WiFi & Wireless Security** — WPA2, deauth attacks, rogue APs, and wireless defense.
5. **Web & App Security** — XSS, SQL injection, CSRF, and OWASP Top 10.
6. **Defense & Privacy** — Firewalls, encryption, VPNs, and incident response.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — Start development server
- `npm run build` — Build for production
- `npm run lint` — Run ESLint
- `npm test` — Run tests
- `npm run validate:lessons` — Validate lesson JSON files

## Tech Stack

- Next.js 16 + React 19
- Tailwind CSS 4
- TypeScript 5
